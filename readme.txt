○概要
レールを簡単に敷く機能を持った自動車モデルを追加します

⚠️ワールド編集ツールのため、ワールドデータが破損する不具合を起こす可能性があります⚠️
　必ずワールドデータのバックアップを取ったうえでご利用ください。

○使い方

---  共通  ---
・自動車モデルで選択後、設置し、右クリックすると使用開始します。
・SuperRailBuilder使用中にQキーもしくは本体を左クリックで編集を終了します。
・もしくはプレイヤーの上に乗ってるブロックを破壊するか、破壊できない場合は一度ワールドを出てもう一度入ってください。


---  SuperRailBuilder レール設置  ---

-操作-
・詳しい操作方法は、操作中に説明が出てきますのでそちらをご覧ください。

-緩和曲線の敷設方法-
1.既設のレールを起点とし、終端をワールド上に選択して線を設定する
2.Oキーを押して緩和曲線の位置と角度を計算する
3.左クリックで選択済みの終端を削除し、表示された位置に近い場所に終端のマーカーを設置する(CTRL+右クリックでより近い位置を選択してください)
4.右クリックでカーブ編集モードを有効化し、カーブ半径がチャット欄のTarget radiusに近づくよう角度を調整する
5.レールを生成する

緩和曲線は計算時の長さとカーブ半径を用いて計算されます。
既設のレールが直線の場合は、1.で設定したカーブ半径に接続する緩和曲線を生成します。
既設のレールが曲線の場合は、既設のレールから直線に接続する緩和曲線を生成します。

-設定-
・描画スクリプト内に設定項目があります。描画スクリプトの設定はマルチプレイにおいて他人に影響を及ぼしません。

・キーの長押しを判定する時間(秒)
  var continueKeyDownTime = 0.2;

・カーソルの限界距離(上限はRTM/Minecraftの仕様に依存します)
  var cursorMaxDistance = 512;

・レールのズレ許容精度のリスト(m)
  この設定はレール分割時に分割可能な地点の許容範囲の計算に使用されます。
  var railPosAccuracyList = [0.03125, 0.0625, 0.125];// 1/32, 1/16, 1/8

・デフォルトのレールのズレ許容精度
  var defaultRailPosAccuracy = 0.03125;

・レール上を選択するとき、端部にスナップする距離
  var railSnapDistance = 5.0;

・レールの幅の一覧
  var railGuageList = {
      guage762: { guage: 762, name: "762mm", maxCant: 105, deficiency: 70 },
      guage1067: { guage: 1067, name: "1067mm", maxCant: 105, deficiency: 70 },
      guage1372: { guage: 1372, name: "1372mm", maxCant: 105, deficiency: 70 },
      guage1435: { guage: 1435, name: "1435mm", maxCant: 200, deficiency: 90 },
      guageMonorail: { guage: 1000, name: "1000mm", maxCant: 150, deficiency: 50 }
  };
  この設定はカントを高さから角度に変換する際に使用されます。
  guageはレール間の長さ(mm)、nameは選択時の表示名、maxCantは最大のカント高さ(mm)、deficiencyは最大のカント不足量です
  ※deficiencyは現在未使用の設定項目になります

・デフォルトのカント量計算に使うレール幅
  var defaultRailGuage = "guage1067";

・カント設定の増減量
  var cantValue = 5;

・カーブと判定する最大のカーブ半径(これ以上大きいカーブ半径は直線扱い)
  var maxCurveRadius = 9999;

・カーブ線プレビューの長さ(m)
  var maxCurveLength = 100;

・複線補助線の間隔
  var sideRailWidth = 4.0;

・複線補助線の数
  var sideRailAmount = 1;
